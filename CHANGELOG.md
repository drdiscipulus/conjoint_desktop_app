# Changelog

All notable changes to Conjoint Companion Desktop are documented here.

## 0.2.0 - 2026-08-14

- Correct test-retest pairing by respondent and profile, independent of row order.
- Add explicit handling and reporting for partial profile replication and incomplete respondents.
- Make the embedded Shiny application the authoritative desktop source.
- Add reproducible Windows and signed/notarized macOS release workflows.
- Harden the desktop shell, dependency checks, and automated tests.

## 0.1.0 - 2026-04-28

- Initial public repository preparation for the desktop publication companion app.
- Added GitHub-facing documentation, citation metadata, GPL-3.0 license text, issue templates, and release instructions.
- Added portable archive and checksum export behavior for manual GitHub releases.
